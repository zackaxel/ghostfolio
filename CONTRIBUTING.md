Thank you for your interest in contributing to WealthNest! We welcome contributions from the community and are grateful for your help in making this project better.

## Getting Started

### Development Setup

1. Fork the repository on GitHub
2. Clone your fork locally
3. Follow the development setup instructions in [DEVELOPMENT.md](./DEVELOPMENT.md)
4. Create a new branch for your changes

### Building and Testing

Before submitting changes:

1. Run the linter: `npm run lint`
2. Run tests: `npm run test`
3. Build the project: `npm run build:production`

## How to Contribute

### Reporting Issues

- Check existing issues before creating a new one
- Use clear, descriptive titles
- Provide detailed reproduction steps
- Include relevant environment information

### Submitting Code Changes

1. **Fork** the repository
2. **Create** a feature branch from `main`
3. **Make** your changes following our coding standards
4. **Test** your changes thoroughly
5. **Commit** your changes with clear, descriptive messages
6. **Push** to your fork
7. **Submit** a pull request

### Pull Request Guidelines

- Keep pull requests focused on a single feature or fix
- Include clear descriptions of changes
- Reference any related issues
- Ensure all tests pass
- Follow existing code style and conventions

## Code Style

- Follow TypeScript and Angular best practices
- Use meaningful variable and function names
- Add comments for complex logic
- Maintain consistent formatting (use Prettier)

## Areas for Contribution

We welcome contributions in these areas:

- **Bug fixes** - Help us identify and fix issues
- **New features** - Enhance the platform with new capabilities
- **Documentation** - Improve guides and API documentation
- **Testing** - Add or improve test coverage
- **Performance** - Optimize code and improve efficiency
- **Accessibility** - Make the platform more accessible
- **Internationalization** - Add support for new languages
